# React Forms Lab — useState() y useRef()

Proyecto didáctico en React + Vite para comparar formularios controlados y no controlados.

## Requisitos
- Node.js LTS instalado.
- Visual Studio Code u otro editor.

## Cómo ejecutarlo
1. Descomprime el ZIP.
2. Abre esta carpeta en Visual Studio Code.
3. Abre una terminal dentro de la carpeta y ejecuta:

```bash
npm install
npm run dev
```

4. Abre en el navegador la dirección que muestra Vite (normalmente `http://localhost:5173`).

## Qué puedes probar
- **useState:** escribe un nombre y observa cómo el estado y el contador de caracteres cambian en tiempo real.
- **useRef:** escribe un nombre y pulsa **Consultar nombre** para leer el valor del campo.
- Usa las pestañas para comparar ambos ejemplos o ver solo uno.

No abras `index.html` directamente. La primera vez necesitas conexión a internet para descargar las dependencias con `npm install`.
